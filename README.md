# Welcome To PitBox.
Let's make your journey to PitBox simple.<br>
First, I'll answer some questions:

Q: What is PitBox?<br>
A: PitBox is a system for viewing Web Pages, DVD, CD, and TV!<br>

Q: Is it physical?<br>
A: It can be both! There is going to be both a Software release<br>
and a way to make it using real hardware!<br>

Q: How do I connect?<br>
A: Enter the server IP in the settings!<br>

Q: What if it doesn't connect properly?<br>
A: You can let us know using the Issues feature, or use our<br>
Featured local listings.
